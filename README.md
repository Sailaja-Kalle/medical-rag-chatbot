# Medical RAG Chatbot
A medical chatbot that answers questions from uploaded research papers using RAG architecture.

## Tech Stack
- Python, LangChain, ChromaDB, HuggingFace Embeddings
- Groq LLM (Llama 3.1), Streamlit UI

## Features
- Upload medical PDFs
- Ask questions and get AI answers with sources
- Chat history saved
- Clear all PDFs and history
